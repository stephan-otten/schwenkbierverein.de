# schwenkbierverein.de

Statische Website des Schwenkbiervereins. Jeder Push auf `main` wird
automatisch über GitHub Pages veröffentlicht (`.github/workflows/pages.yml`).

- `index.html` – Startseite
- `CNAME` – eigene Domain für GitHub Pages

Die Seite wird von Claude (Cowork) gepflegt; Änderungswünsche gehen über Stephan.
